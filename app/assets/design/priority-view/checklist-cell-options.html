Option C · For the design team, not for participants

Showing checklist progress in a cell

Control measures and response options are checklists. Some items are done, and some still need review. This page compares ways to show that in one cell, without saying the same thing twice.

Option C is unchanged for now. At the moment it uses option 3, both numbers.

What the cell needs to do

  • Say one thing once. "7 of 8 need review" and "1 of 8 done" are the same fact, so showing both is repetition.
  • Match the other columns. A higher number is worse, and worse is red. Risk of incursion and impact already work this way.
  • Be clear what the bar shows. It should not be read as "the amount that needs review" when it shows what is done, or the other way round.
  • Work for colour blindness. Colour is never the only cue, and shapes next to each other differ in lightness by at least 3:1.
  • Fit the cell and the card. The cell is about 150px wide.

What each one does

Notes on each option
Option Good for Watch for
1. Done only One number, and a plain progress bar that everyone already understands The wrong way round. A low number is bad here, but a high number is bad in risk and impact. Nothing is red, so it loses the signal that something is worse
2. Review only One number, once. A high number is worse and red, like the other columns. The simplest cell No picture of the proportion. People have to compare "7 of 8" and "6 of 10" in their head. The colour block helps, but it is only five steps
3. Both (current) Everything is there, and the bar has its own label Repetition. Two numbers say the same thing, and the cell has four lines. The bar's green fills up as the red count goes down, which is two directions in one cell
4. Red segments, with block One number, once. The bar shows what is outstanding, in red, filling from the left like the risk and impact bars. More red is worse in every column. The cell keeps the same block as the other columns Red appears twice, in the block and in the bar. Even 2 red segments look alarming, although the block says it is fine. The block and bar colours can disagree
5. Red segments, text only The quietest option with a picture. One line of text and one bar, with no block The two checklist columns no longer have the muted block that the other four columns have, so the row looks less consistent. Fewer levels of colour, because the bar is always red
6. Red and green segments Shows done and outstanding in two colours, so it reads without a caption Fails for red-green colour blindness. Red and green are 1.55:1, so the two colours look almost the same. See below. It would need a pattern as well, which adds clutter

Contrast and colour blindness

Segments that sit next to each other must differ by at least 3:1 in lightness, so that the difference does not depend on hue. Red against green is the classic problem, because they can be the same lightness.

These are simulations on screen, and a guide, not a test with people. The text always carries the number, so the bar never has to be read by colour alone.

Suggestion

Option 4: show the review count once, with red segments for what is outstanding. It removes the repetition, because the number is "7 of 8 need review" and the bar is the same thing as a picture. It matches the rest of the table, where more is worse and worse is red, and the bar fills from the left like the risk and impact bars. Filled and empty segments are the cue, so it works in greyscale and for every kind of colour blindness.

Option 5 is the leaner fallback. If the cell still feels busy, drop the colour block and keep one line of text and the red bar. The cost is that the two checklist columns look different from the other four.

Avoid option 6, because red and green cannot be told apart by lightness. Avoid option 1, because it reverses the direction. Option 3 is what we have now, and it is the one with the repetition.

Still to decide

  • Segment colour. Always red, as shown, or the colour of the block (green when few are outstanding)? The second avoids a few red segments looking alarming, but it brings the red and green problem back.
  • Words. "need review" or "to review"? Would "outstanding" be clearer?
  • All done. An empty bar with "0 of 8 need review" could read as "no data". A tick or "All done" could be clearer.
  • Test it. Ask what the bar shows, and whether more red means better or worse.
